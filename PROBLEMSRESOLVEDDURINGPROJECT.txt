- moviepy 2.2.1 uses `with_duration()` not `set_duration()`

- moviepy 2.2.1 uses `with_audio()` not `set_audio()`

- TextClip in 2.2.1 doesn't accept `fontsize` parameter

- ImageClip doesn't have `resize()` method - must resize before creating clip

- `write_videofile()` doesn't accept `verbose` parameter

- Text rendering must be done with PIL, then converted to numpy arrays

## Technical Challenges & Solutions

### Challenge 1: MoviePy API Compatibility

**Problem**: Different versions of moviepy have different APIs**Solution**: Adapted to moviepy 2.2.1 API with `with_*` methods instead of `set_*` methods

### Challenge 2: Text Rendering

**Problem**: TextClip API kept changing and rejecting parameters**Solution**: Used PIL (Pillow) to create text images, then converted to numpy arrays for moviepy

### Challenge 3: Image Resizing

**Problem**: ImageClip doesn't have resize() method**Solution**: Resize images using PIL before creating ImageClip

### Challenge 4: Audio Synchronization

**Problem**: Scenes were too short (3 seconds) instead of matching audio duration**Solution**: Used actual audio duration from Google Text-to-Speech files

### Challenge 5: Text Visibility

**Problem**: Text was too small to read**Solution**: Created large text overlays (48pt titles, 32pt subtitles) with semi-transparent backgrounds

### Challenge 6: Image Downloads

**Problem**: Unsplash API sometimes failed**Solution**: Created colored placeholder images when downloads failed

def create_background_image(width, height, color, text=""):
    """Create a background image with solid color."""
    img = Image.new('RGB', (width, height), color=color)
    return img


def download_image_from_unsplash(query, filename, width=1280, height=720):
    """Download image from Unsplash or create placeholder."""
    if os.path.exists(filename):
        return filename
    
    print(f"  Downloading image for: {query}...")
    url = f"https://source.unsplash.com/{width}x{height}/?{query}"
    
    try:
        headers = {'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64 )'}
        req = urllib.request.Request(url, headers=headers)
        with urllib.request.urlopen(req, timeout=10) as response:
            with open(filename, 'wb') as out_file:
                out_file.write(response.read())
        print(f"  ✓ Image downloaded")
        return filename
    except Exception as e:
        print(f"  ✗ Download failed. Creating placeholder...")
        color = (70, 130, 180)
        placeholder = create_background_image(width, height, color, query)
        placeholder.save(filename, 'JPEG', quality=85)
        return filename


def generate_voice_audio(text, output_path, lang='en'):
    """Generate voice audio using Google Text-to-Speech."""
    print(f"  Generating voice narration...")
    try:
        tts = gTTS(text=text, lang=lang, slow=False, tld='co.in')
        tts.save(output_path)
        print(f"  ✓ Voice audio generated")
        return output_path
    except Exception as e:
        print(f"  ✗ Error generating voice: {e}")
        raise


def wrap_text(text, max_width, font):
    """Wrap text to fit within max width."""
    words = text.split()
    lines = []
    current_line = []
    
    for word in words:
        test_line = ' '.join(current_line + [word])
        bbox = font.getbbox(test_line)
        width = bbox[2] - bbox[0]
        
        if width <= max_width:
            current_line.append(word)
        else:
            if current_line:
                lines.append(' '.join(current_line))
            current_line = [word]
    
    if current_line:
        lines.append(' '.join(current_line))
    
    return lines


def create_text_overlay_image(title, subtitle, width=1280, height=200):
    """Create a text overlay image with title and subtitle."""
    # Create semi-transparent background
    overlay = Image.new('RGBA', (width, height), (0, 0, 0, 180))
    draw = ImageDraw.Draw(overlay)
    
    try:
        # Try to load a larger font
        title_font = ImageFont.truetype("arial.ttf", 48)
        subtitle_font = ImageFont.truetype("arial.ttf", 32)
    except:
        # Fallback to default font
        title_font = ImageFont.load_default()
        subtitle_font = ImageFont.load_default()
    
    # Draw title
    title_bbox = draw.textbbox((0, 0), title, font=title_font)
    title_width = title_bbox[2] - title_bbox[0]
    title_x = (width - title_width) // 2
    draw.text((title_x, 20), title, fill=(255, 255, 0, 255), font=title_font)
    
    # Draw subtitle with text wrapping
    subtitle_lines = wrap_text(subtitle, width - 40, subtitle_font)
    y_offset = 80
    for line in subtitle_lines[:3]:  # Max 3 lines
        subtitle_bbox = draw.textbbox((0, 0), line, font=subtitle_font)
        line_width = subtitle_bbox[2] - subtitle_bbox[0]
        line_x = (width - line_width) // 2
        draw.text((line_x, y_offset), line, fill=(255, 255, 255, 255), font=subtitle_font)
        y_offset += 40
    
    return overlay

            img_array = np.array(img_pil)

        except Exception as e:

            bg_img = create_background_image(VIDEO_WIDTH, VIDEO_HEIGHT, scene['color'])
            bg_array = np.array(bg_img)

        bg_array = np.array(bg_img)
        bg_clip = ImageClip(bg_array).with_duration(duration)
    
    # Create text overlay
    overlay_img = create_text_overlay_image(scene['title'], scene['voice_script'], VIDEO_WIDTH, 200)

### 2. Text Rendering in Video

- PIL (Pillow) text rendering + numpy conversion is more reliable

- Always create text with semi-transparent backgrounds for readability

### 3. Image Handling

- Always resize images before creating ImageClip

- Use PIL for image operations, then convert to numpy arrays

- Handle download failures gracefully with placeholder images

### 4. Audio Synchronization

- Use actual audio file duration, not arbitrary durations

- Google Text-to-Speech provides consistent, natural-sounding narration

- Audio codec 'aac' is more compatible than 'libmp3lame'

### 5. Project Structure

- Separate concerns: audio generation, image processing, video composition

- Create temporary files for intermediate steps

- Clean up temporary files after successful completion

- Log progress at each step for debugging

### 6. Error Handling

- Always have fallback options (placeholder images, default fonts)

- Continue processing even if individual scenes fail

- Provide detailed error messages for debugging
